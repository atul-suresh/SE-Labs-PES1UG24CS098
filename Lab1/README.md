# Software Engineering Lab 1

## Problem Statement

**Problem Statement #22**

**Smart Parking Space Rental & License Validator**

## Domain

Smart Cities, Transport & Logistics

## Actors

- Vehicle Owner
- Parking Warden

## System Overview

The system supports real-time parking bay reservations, vehicle license-plate validation, vehicle entry and exit recording, progressive hourly billing, and detection of unauthorized overstays.
